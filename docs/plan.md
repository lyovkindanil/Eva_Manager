# План

Масштаб: сейчас около 100 пользователей и 3 сервера, через год 10–20
серверов и сервис с продажей доступа. Панель бесплатная, с открытым кодом.
MVP — этапы 0–3.

1. **Этап 0. Каркас — выполнен (PR #1).** Go-модуль, база SQLite /
   PostgreSQL с миграциями (обе в CI), интерфейс в бинарнике, Docker-образ.
   Xray как дочерний процесс: проверка конфига `xray run -test`, перезапуск
   после падения, gRPC API. Модель «узел» с первого дня.
2. **Этап 1. Ядро Xray — выполнен (PR #2, #3).** VLESS Reality,
   генерация конфига и ссылки из одной модели, опция VLESS Encryption
   (mlkem768x25519plus — клиент VPN4Eva его уже понимает), версии конфига
   и откат, сквозной тест «ссылка панели → парсер VPN4Eva → подключение».
   Пользователи через API Xray, трафик, лимиты и сроки, подписка
   `/sub/<токен>` (`profile-title` с кириллицей — в base64-форме
   `base64:…`).
3. **Этап 2. AmneziaWG — выполнен.** amneziawg-go рядом с Xray: по
   процессу `eva-manager awg-run` на интерфейс (падение одного не трогает
   панель и Xray), NAT через iptables, пир на пользователя, трафик из
   счётчиков UAPI (тех же, что у `awg show`), `vpn://` в подписке (формат —
   официальный AmneziaVPN: base64url от qCompress JSON, его понимают и
   VPN4Eva, и приложение AmneziaVPN), тест с клиентом VPN4Eva.
4. **Этап 3. Интерфейс и установка — конец MVP.** Вход, мастер первого
   запуска, экраны пользователей, инбаундов, журнала и настроек, QR-коды.
   `install.sh` для Ubuntu / Debian и `docker compose`.
5. **Этап 4. Несколько серверов.** Агент на узле (тот же бинарник), mTLS,
   одна подписка на все узлы, общий учёт трафика.
6. **Этап 5. Больше протоколов.** Hysteria2 отдельной службой рядом с Xray
   (Xray его не поддерживает), VLESS grpc / ws, TLS с Let's Encrypt,
   WireGuard.
7. **Этап 6. Статистика и удобство.** Графики, сброс трафика по расписанию,
   лимит устройств, 2FA, журнал действий, Telegram-бот, импорт из 3x-ui.
8. **Этап 7. Сервис.** API оплаты и личного кабинета (например, оплата из
   клиента VPN4Eva), администраторы с ролями.
